# Image Accordion 🖼️🐕

An interactive image accordion showcasing beautiful dog photos! 🐶 Click on any image to expand it and see the full view. Perfect for pet lovers and web developers learning CSS animations.

## Features ✨
- Smooth accordion animation
- Responsive design 📱
- Adorable dog images 🐕‍🦺
- Easy to customize

## Live Demo 🌐
Check out the live demo: [https://iam269.github.io/Image-Accordion/](https://iam269.github.io/Image-Accordion/)

## Technologies Used 🛠️
- HTML5
- CSS3
- JavaScript

## How to Use 🚀
1. Clone the repository
2. Open `index.html` in your browser
3. Click on images to expand them!

Enjoy the cute dogs! 🐾
